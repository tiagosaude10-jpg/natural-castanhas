# Natural Castanhas — PWA

Primeira versão funcional do aplicativo, com:

- Tela inicial de comandos;
- Núcleo 1 — Compras e controle da castanha;
- Cadastro, pesquisa, filtro, finalização e exclusão de compras;
- Cálculos de capital, compras, saldo e pagamentos;
- Armazenamento local no aparelho;
- Instalação como PWA no Android e iPhone;

## Publicar no GitHub Pages

1. Crie um repositório chamado `natural-castanhas`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve. O link será semelhante a `https://seuusuario.github.io/natural-castanhas/`.

## Instalar no Android

Abra o endereço no Chrome e toque em **Instalar aplicativo** ou **Adicionar à tela inicial**.

## Instalar no iPhone

Abra o endereço no Safari, toque em **Compartilhar** e escolha **Adicionar à Tela de Início**.

## Observação importante

Nesta primeira versão, os dados são guardados no próprio navegador com `localStorage`. Para permitir que Tiago, Hélio e outros usuários visualizem os mesmos dados em aparelhos diferentes, a próxima etapa deverá conectar o aplicativo a um banco de dados com login.
